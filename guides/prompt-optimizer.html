Prompt optimizer: how to optimize a prompt in five checks

A prompt optimizer finds what the model would have to guess and fills it in. You can run the same five checks yourself on any prompt for ChatGPT, Claude, or Gemini.

What a prompt optimizer does

Most weak answers come from short prompts, not weak models. "Write a blog post about saving money" leaves the model to guess the reader, the length, the tone, and the shape. It guesses the most generic option for each. An optimizer keeps your task and adds the missing details, so the first answer is closer to what you wanted.

The five checks

  1. Role. Who should the model act as? "You are a personal finance writer" sets vocabulary and depth.
  2. Task. One clear sentence about the job: write, fix, summarize, compare, plan.
  3. Reader. Who is the result for? A beginner, a hiring manager, a customer, a ten-year-old.
  4. Format. A list, an email, a table, three options, code with comments. Say the shape you want back.
  5. Limits. Length, scope, and what to leave out. "About 600 words. No generic tips like 'make a budget'."

One more line helps almost every prompt: "If something essential is missing, ask me one question before you start." The model asks instead of inventing.

Before and after

Before

Write a blog post about saving money.

After

You are a personal finance writer. Write a blog post about saving money for people in their twenties who are new to budgeting. Use a short intro, five specific tips with a real example each, and a one-line takeaway. Keep it around 600 words, friendly but direct. Leave out generic advice like "make a budget". If something essential is missing, ask me one question before you start.

Questions

Is a prompt optimizer the same as a prompt generator?

No. A generator writes a new prompt from a topic. An optimizer starts from your prompt and improves it, so your intent stays. More on the difference.

Does an optimized prompt work in Claude and Gemini too?

Yes. The five checks help every chat model, not just ChatGPT.

How long should a prompt be?

Long enough to answer the five checks, which is usually three to six sentences. Longer is fine when you paste source material for the model to use.

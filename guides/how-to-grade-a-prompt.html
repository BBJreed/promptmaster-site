How to grade an AI prompt

A useful grade tells you what the model has to guess. PromptMaster scores the draft you paste in and, with Pro, replaces it with a prompt that states the role, the task, and the format.

1. Start from a weak draft

“Write a blog post about productivity” looks short enough to send. It does not say who it is for, how long it should be, or what to leave out. That is the kind of prompt worth grading. The job chips on the home screen fill in drafts like that on purpose.

2. Tap Grade and rewrite

The grade runs without an API key. The first five grades are free. The result shows a score and an explanation of the gaps. It does not require you to pick a model first.

3. Read the flaws before the rewrite

Look for a missing role, a missing audience, no constraints, and no output format. Those four are why a short prompt gets a low score. Fixing them is what the rewrite is for.

4. Send the rewrite into the chat you already use

Pro shows the full rewritten prompt. Tap ChatGPT or Claude and that app opens with the text filled in. Tap Gemini and the rewrite is copied, because Gemini does not accept a prefilled link. Tap More for the Android share sheet. You still press send in the other app. An API key is only needed if you want PromptMaster to run the answer inside the app.

You can also copy the prompt of the day without grading it. That one is already written. Grading is for the prompt you were about to send.
